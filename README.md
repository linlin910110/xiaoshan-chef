# 小膳 / 老灶 · 双模式菜谱助手

一个纯前端单页应用，接入 Agnes 大模型。两种模式共用同一个 API Key，随时切换：

| 模式 | 人设 | 适合 | 板面 |
| --- | --- | --- | --- |
| **健康模式** | 小膳（注册营养师 × 中餐厨师） | 每天吃什么、控卡控蛋白、按目标配餐 | 今日菜单（热量 / 蛋白质累计）、小膳的搭配口诀 |
| **家常模式** | 老灶（老师傅） | 想学某道家常菜的地道做法 | 我的菜谱本（按菜系归档）、老灶的基本功 |

两个模式的板面内容、对话历史各自独立保存，切回来还是原样；Key、模型、目标、忌口是共用的。

## 一、怎么打开

**只有一个入口：本地服务版 `http://127.0.0.1:8137/`。** 双击 `index.html` 也会被自动带到这个地址，所以你怎么开都是同一个界面、同一份数据。

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 双击 `index.html` | 双击文件本身 | 页面会探测本地服务，**在跑就自动跳过去**；没跑就提示你先启动服务 |
| 双击 `start.cmd` | 启动服务并自动开浏览器 | 黑窗口别关，关了就停服 |
| 手动 | `node serve.mjs 8137` | 同上，端口可改；加 `--no-open` 不自动开浏览器 |

为什么要多一个本地服务：`file://` 和 `http://127.0.0.1:8137` 在浏览器眼里是**两个不同站点**，API Key、上次用的模式、今日菜单/菜谱本各存一份，所以直接双击打开会像"另一个应用"。现在 `file://` 页只做一件事——把你送去服务版，两份状态就不会再打架。

**如果你要在聊天窗口、预览器、别的电脑上打开**：用 `小膳.html`。它是单文件版，样式和脚本全部内联，不依赖同目录的 `styles.css` / `core.js` / `app.js`，任何能渲染 HTML 的地方打开都有完整界面。改完源码后运行 `node build.mjs` 重新生成。

需要 Node.js 18+；`start.cmd` 会先检查 Node。

## 二、第一次使用（三步）

1. 点右上角 **API 设置**，粘贴 Agnes API Key（`sk-` 开头，在 <https://platform.agnes-ai.cn> 生成）。**两种模式共用一个 Key，填一次就行。**
2. 点 **测试连通**：会先拉取模型列表，再发一句极短的对话，两段耗时分别显示。
3. 点 **保存**，然后生成菜单 / 按菜系点菜，或者直接在搜索框里搜。

## 三、健康模式（小膳）

- **生成今日菜单**：按「早餐 / 午餐 / 加餐 / 晚餐」配餐，给热量、蛋白质、耗时、食材份量、步骤，以及「为什么这么配」；底部附今日小建议。
- **搜索菜谱**：输入食材、口味、场景（“冰箱里只有番茄和鸡蛋”“15 分钟快手菜”“控糖晚餐”）。
- **快捷筛选**：低卡减脂 / 高蛋白 / 素食 / 快手 / 控糖 / 带饭。
- **今日已选**：卡片点「加入今日菜单」，右侧累计总热量与总蛋白质，可单条删除或清空。
- **和小膳对话**：连续对话，支持“换一道”“太油了”“改成带饭版”，回答里的菜谱自动渲染成可加入菜单的卡片。

## 四、家常模式（老灶）

- **按菜系点菜**：川 / 粤 / 鲁 / 苏 / 湘 / 浙 / 闽 / 徽 / 东北 / 西北 / 云贵 / 港式，一次给 4–6 道代表菜。
- **随便来一道**：不知道吃啥时随机挑一个菜系出菜。
- **每道菜都有**：菜系徽标、难度、耗时、口味，食材与份量、分步做法，以及高亮的 **🔑 关键一步**（最容易翻车的那一步：火候、油温、勾芡次数、下锅顺序）。
- **我的菜谱本**：点「收进菜谱本」按菜系归档，底部显示「共 N 道 · 覆盖 M 个菜系」，可清空。
- **和老灶对话**：“鱼香肉丝为什么不出红油”“换成不辣的版本”“教我糖醋排骨”，做法细节讲得比列表更细。

设计原则：家常模式追求**地道**，不为了健康指标去改配方；健康模式才负责配比和热量。

## 五、接口与实现要点

- 端点：`POST https://api.agnes-ai.cn/v1/chat/completions`，OpenAI 兼容；模型列表 `GET /v1/models`。
- 默认模型 `agnes-2.5-flash`（当前免费），可选 `agnes-3.0-flash`、`agnes-2.5-pro`；测试连通后用接口返回的真实列表刷新下拉框。
- 结构化输出走 `response_format: {"type":"json_object"}`，再本地抽取 JSON（容忍 ```json 代码块、前后废话、字符串里带 `}`），归一化成固定字段，模型偶尔不听话也不会把界面弄崩。
- 对话走 SSE 流式（`stream: true`），逐字上屏；流式失败自动退回整段请求。
- 无需后端：Agnes 的 CORS 为 `access-control-allow-origin: *`，浏览器可直连。
- 模式状态：`localStorage` 里 `xiaoshan.mode` / `xiaoshan.histories` / `xiaoshan.view` 分模式存，切换时重放上一屏。

## 七、文件结构

```
agnes-chef/
├─ index.html        页面结构（走本地服务；file:// 打开会自动跳转）
├─ 小膳.html         单文件版（样式 + 脚本全内联，发给别人 / 丢进预览器用这个）
├─ styles.css        样式（响应式，窄屏单列）
├─ core.js           纯逻辑：双人设提示词、JSON 抽取、归一化、错误映射
├─ app.js            交互：模式切换、请求、流式渲染、菜单 / 菜谱本、设置
├─ build.mjs         生成单文件版
├─ serve.mjs         零依赖本地静态服务器
├─ start.cmd         双击启动
├─ shots/            真机截图（首页 / 菜单 / 已选 / 搜索 / 家常 / 菜谱本 / 设置 / 提示页）
└─ test/
   ├─ core.test.js   81 条单元测试
   ├─ static-check.js id / 导出 一致性检查
   ├─ ui-mode.mjs    双模式切换与显隐检查（不发 API）
   ├─ file-open.mjs  双击 index.html 是否跳到服务版
   ├─ file-gate.mjs  服务未启动时的提示与自动恢复
   ├─ single-file.mjs 单文件版样式内联是否生效
   ├─ e2e.js         真打 Agnes 的端到端验证
   └─ ui-shot.mjs    CDP 驱动 headless Edge 跑真实交互并截图
```

## 八、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `✗ API Key 无效或已过期（401）` | Key 复制不全或已重置，去 platform.agnes-ai.cn 重新生成 |
| `✗ 请求太频繁或额度用尽（429）` | pro 系列按量计费，余额不足或被限流，换 flash 模型 |
| `✗ 请求被拒绝（400）：...` | 通常是模型 id 不存在，点一次「测试连通」让下拉框按真实列表刷新 |
| `✗ 请求超时` | 网络到 api.agnes-ai.cn 不稳，重试；公司代理会拦 SSE |
| 切换模式后板面空了 | 每个模式各自记着上一屏；在该模式里生成或搜索一次就会有内容 |
| 设置里找不到「每日目标 / 忌口」 | 这两项只属于健康模式，切回家常模式时会隐藏 |
| 界面能开但按钮无反应 | 确认 `core.js` 和 `app.js` 与 `index.html` 同目录，且没被浏览器插件拦截 |
| 双击 `index.html` 只看到"请从本地服务打开" | 本地服务没在跑：双击 `start.cmd`（黑窗口别关），页面会自动跳过去；或点浮层上的「直接打开服务版」 |
| 想开机就能双击打开 | 把 `start.cmd` 的快捷方式放进 `shell:startup`，开机自动起服务（需要的话让我加） |
| 打开后是白底黑字、没样式 | 那个环境拦掉了外链的 `styles.css`（聊天窗口、预览器、沙箱常这样）：改用单文件版 `小膳.html` |
